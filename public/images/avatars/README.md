# Preset avatars

Source: DiceBear API, `personas` style (https://www.dicebear.com/styles/personas/).

Artwork: "Personas" by Draftbit (https://personas.draftbit.com/), licensed under
CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

Each file is a deterministic render with a paper background (`#f7f4ec`) and one
seed per preset. The seeds are Amber, Basil, Cedar, Dune, Ember, Fern, Grove,
Harbor, Iris, Juniper, Kelp, and Lark.

These files are committed so the demo works offline and the page satisfies the
self-hosted image policy. Do not swap them for live API URLs.
